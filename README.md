# Лапки & Подушки 🐾

Адаптивный одностраничный учебный сайт бутик-отеля для кошек и собак. Пользователь выбирает комнату на интерактивном плане или в каталоге, фильтрует номера, рассчитывает стоимость и оформляет или отменяет демо-бронирование.

## Технологии

HTML5, CSS3, Vanilla JavaScript (ES6-модули), localStorage. Без фреймворков, сборщиков, сервера, регистрации и оплаты. Визуальные эмодзи доступны без установки библиотек. Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты.

## Возможности

- 8 комнат; №3 и №6 заняты изначально.
- Интерактивный план с ресепшеном, коридором, игровой зоной и двориком.
- Синхронный выбор комнаты на плане и в каталоге.
- Фильтрация по виду питомца, цене и вместимости.
- Проверка имени, вида животного, количества питомцев и ночей (1–30).
- Автоматический расчёт стоимости номера и дополнительных услуг.
- Сохранение бронирований в localStorage, отмена, сброс демо-данных.
- Диалоги подтверждения, уведомления, доступность клавиатурой и мобильная адаптация.

## Запуск через Live Server

1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.
4. Откройте выданный локальный адрес в браузере.

**Важно:** из-за ES-модулей не рекомендуется запускать файл двойным кликом по `index.html` через `file://`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий GitHub и загрузите все файлы из папки проекта в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, сохраните.
5. Дождитесь публикации и откройте адрес, предоставленный GitHub Pages.

## Учебный характер проекта

Все бронирования учебные, хранятся только в текущем браузере. Реальных услуг, оплаты, дат заезда и серверной синхронизации нет. Один номер бронируется целиком до отмены. Изначально занятые комнаты нельзя освободить. Если localStorage недоступен, изменения сохраняются только в памяти вкладки и пользователь получает уведомление.

## Использование нейросети

При разработке использовался ChatGPT (OpenAI) для генерации структуры интерфейса, CSS и логики на JavaScript. Примеры промптов:

1. «Создай адаптивный сайт бутик-отеля для питомцев на HTML, CSS и Vanilla JS без фреймворков».
2. «Реализуй синхронизацию интерактивной схемы восьми номеров с каталогом и фильтрами».
3. «Добавь валидацию формы, динамический расчёт стоимости, сохранение и отмену бронирований в localStorage».

## Структура

- `index.html` — семантическая разметка разделов и формы.
- `style.css` — стили, адаптивность, состояния, анимации.
- `data.js` — единый источник данных номеров и услуг.
- `main.js` — состояние, фильтрация, интерфейс, расчёты, валидация, хранение.

## Проверка

Рекомендуется вручную проверить выбор через план и каталог, фильтры, занятые комнаты, валидацию пустых/дробных/отрицательных значений, перерасчёт услуг, повторное подтверждение, обновление страницы, отмену, сброс и клавиатурную навигацию. Автоматические браузерные тесты в комплект не входят.


## Обновлённый визуальный стиль
Дизайн переработан по предоставленному шестому референсу: яркий коралловый, розовый, сиреневый, иллюстративные карточки услуг и крупная игровая типографика. Оригинальные изображения пользователя 1–5 и 7 включены локально в `assets/` и работают без интернета.

### Обновление иллюстраций

Иллюстрация `hero-pets.png` используется только в главном блоке. Для первых трёх кошачьих номеров используются `cat-sleeping.png`, `cat-stretching.png`, `cat-playing.png`.
